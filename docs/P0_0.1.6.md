# P0: agent reliability (0.1.6)

Android versionName 0.1.6 / versionCode 10; MCP server and gateway version 0.1.6.
Android advertises 29 tools. iOS-only bridge/simulator tools keep their independent
versions and do not acquire Android automation capabilities.

## Changes

- Correct native `ui_wait` and `ui_assert` text evaluation. `expected` compares
  actual text instead of merely accepting a selector match. Exact, case-sensitive
  comparison is the default; direct callers may request contains/ignore-case.
- Reject ambiguous text predicates. Preserve text-selector semantics when no
  explicit expectation is supplied. Empty expected text is a real expectation.
  Preserve `ui_assert`'s expected-only form by inferring an exact text selector
  for nonempty expectations.
- Require a window and the correct foreground package for every predicate, including
  absence and zero count. Without `package_name`, bind to the initial foreground
  app (or the first window observed when starting without one).
- Never establish an exact count from a capped match list. A result at the native
  100-match cap yields `truncated_count`.
- Add MCP `structuredContent` alongside text/images. Predicate results include
  expected/actual, reason, elapsed time, truncation and retryability.
- Route assertions use the same native evaluator, with structured step outcomes.
  Remove the YAML visibility-rewrite workaround. Escape the parameter-reference
  regex closing brace for Android's ICU engine; JVM-only tests did not expose this.
- Add `get_capabilities`: per-tool implementation/blocker status, execution location,
  conditional requirements, mutation/restoration risk and unsupported controls.
- Make launch-readiness timeouts, missing restoration snapshots and partial
  restoration explicit errors. Partial restoration retains the snapshot; successful
  restoration checks stored rotation/font/night-mode/animation settings and media
  volume. QA session finalization cannot label a restoration failure as PASS.
- Check settings-write return values instead of declaring rejected writes successful.
- Guard Android 16 notification APIs on API 35. Keep minSdk 35 and compile/target 37;
  Android 15 uses the ordinary foreground notification.

## Validation

Validation used disposable, explicitly provisioned emulators, not the connected
physical device. The previously installed physical artifact was not replaced.

| Environment | Scope exercised |
| --- | --- |
| API 35 / Android 15 | Startup, foreground notification/server, MCP discovery, native text success/failure, wrong-package absence/count, screenshot/tree failure evidence, capability output, route text parity and consent acceptance/rejection. Partial restoration retained its snapshot and a permission-provisioned retry succeeded. |
| API 36 / Android 16 | The API 35 checks plus explicit accessibility-unavailable failure after disabling the service. |
| API 37 / Android 17, 16 KB page image | The same direct MCP suite, on-device route parity, consent rejection/acceptance, missing-snapshot failure, partial restoration/retry and accessibility-unavailable failure. Final source was rechecked on this image. |

These are focused smoke/regression checks, not certification of every OEM,
camera, background-lifetime or accessibility edge case. The API 35/36 checks
were performed during development of 0.1.6; API 37 was also rerun after final
restoration/capability changes.

Reproducible code checks:

```bash
./gradlew :shared:testAndroidHostTest :androidApp:assembleDebug :androidApp:lintDebug
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tools -p test_qa_gateway_mcp.py
```

The host suite covers pure text/window/package/count predicates, route compilation
and evaluator parity, structured MCP serialization and existing regressions.
Gateway tests preserve structured failures and their failed report status.
Android lint passes with existing warnings; optional ADB-provisioned secure-settings
permission is explicitly documented/suppressed like the existing READ_LOGS permission.

Opt-in live checks:

```bash
export TESTER_MCP_URL=http://127.0.0.1:18080/mcp
export TESTER_MCP_SESSION='<already approved session ID>'
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tools -p test_android_agent_mcp.py
```

Use a disposable emulator/test device with Tester in the foreground and accessibility
enabled. The script does not install builds, grant permissions, approve tools or
modify settings. It deliberately triggers assertion failures and screenshot/tree
capture; do not run it over personal or confidential UI.

## Remaining work

P1-P5 retain the versions in
[`AGENT_QUALITY_IMPLEMENTATION_PLAN.md`](AGENT_QUALITY_IMPLEMENTATION_PLAN.md).
This release does not provide combined waits, container selectors, observation-bound
element references, durable run recovery, redacted failure bundles or privileged
environment controls.

Snapshot ownership, touched-field-only restore and crash recovery remain P3 work.
P0 verifies stored settings; it does not promise that every OEM immediately applies
the requested dark-mode configuration or display rotation. Capability status is
informational, not execution approval or a guarantee about a future window.
